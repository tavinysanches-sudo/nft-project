# NFTERRA

A responsive NFT collection interface developed with React.

## About

NFTERRA is a fictional NFT collection website created as part of a Frontend development project.

The project includes reusable React components, responsive layouts, hover effects and entrance animations.

## Technologies

- React
- JavaScript
- CSS
- Vite
- Animate.css
- Git
- GitHub
- GitHub Pages

## Features

- Responsive design
- NFT card component
- Card list component
- Responsive header
- Hover effects
- Card entrance animations
- Different NFT data
- Mobile and desktop layouts
